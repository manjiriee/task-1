Iris Flower Classification – Machine Learning Project

 Project Overview
This project focuses on building a Machine Learning classification model using the Iris dataset. 
The objective is to classify iris flowers into three species:
- Setosa
- Versicolor
- Virginica

The dataset was provided as part of the internship task.

Technologies Used
- Python
- Scikit-learn
- Pandas
- VS Code

Steps Performed
1. Imported the Iris dataset using Scikit-learn.
2. Explored features such as sepal length, sepal width, petal length, and petal width.
3. Split the dataset into training and testing sets.
4. Trained a classification model.
5. Evaluated the model using accuracy score.



 Model Evaluation
The model was tested on unseen data and achieved good accuracy.
This project demonstrates understanding of:
- Supervised Learning
- Classification
- Train-Test Split
- Model Evaluation



 How to Run the Project
1. Install required libraries:
   pip install scikit-learn pandas
2. Run the Python file:
   python Iris.py



 Conclusion
